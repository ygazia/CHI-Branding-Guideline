Clear space and minimum size for the CHI mark and line lockups.

**Use**
- X is the width of the letter I, which is one eighth of the mark's width. Keep at least 1X clear on all four sides; aim for 2X on pack fronts and posters.
- Minimum widths: 60 px or 12 mm for the mark, 96 px or 20 mm for a line lockup. Below that, use the mark alone.

**You provide**
- The logo width. Everything else follows from it: X = width / 8.

**Do not**
- Let type, image edges, folds or other logos enter the clear space.
