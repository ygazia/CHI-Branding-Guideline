The three button levels: a red primary, an outlined secondary, and an underlined text link.

**Use**
- One primary (`brand` fill, `on-brand` label) per view, for the action the page exists for. Hover is `brand-strong`.
- Secondary (1px `ink` border) for the alternative. Text link (`brand-text`, underlined) for everything else.
- Labels are `body-strong`, sentence case, two or three words that start with a verb.
- Corners are `radius-none`. Padding is `space-3` by `space-6`. Minimum touch target 44px.
- Focus is a 2px `focus` ring offset 2px.

**You provide**
- The label and the action. Disabled buttons say why in the label ("Sold out"), not just "Unavailable".

**Do not**
- Put two red buttons side by side, set labels in capitals, or round the corners.
