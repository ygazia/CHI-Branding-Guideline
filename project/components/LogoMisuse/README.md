Eight ways the logo must not be treated, shown on the real artwork.

**Use**
- Show this card to agencies, printers and partners when briefing work.
- If a layout seems to need one of these treatments, change the layout: move the logo to a calmer area, switch to the white version, or give it more space.

**Do not**
- Stretch, rotate, recolour, outline, add effects, place on red, orange or pink grounds, recolour the descriptor, or enclose the mark in a badge or circle.
