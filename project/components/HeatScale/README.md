A three-band temperature guide for styling tools and heat-protection content, running `heat-low`, `heat-mid`, `heat-high`.

**Use**
- On tool pages, pack inserts and education material, to help people choose a setting.
- Each band darkens as temperature rises, so the order reads without colour.

**You provide**
- The temperature range for each band, in both °F and °C, taken from the tool's own published settings. The ranges in the preview are examples.
- A hair-type label for each band in `descriptor-s`.

**Do not**
- Use the heat colours for anything other than temperature.
- Blend the bands into a gradient.
